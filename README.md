# vehicle-security
# overview
vehicle theft detection using keypad-based security system, here i use keypad for passwaord entry, LCD for displaying system's status, DC motor for activates the ignition key if entered password is correct. GSM 900A module for sending sms alerts to the mobile phone.  If the entered password is correct, the DC motor activates the ignition key. Afetr 3 attempts, the motor locked and GSM sends the alert message to the owner's phone.

Arduino IDE
